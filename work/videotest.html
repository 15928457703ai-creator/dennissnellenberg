    裂变

    从“有得看”

    到“看得爽”

    通过预加载与无打断逻辑，保证“上下滑动”的绝对流畅与沉浸感。

    最后看完想做

    轻交互唤起评论，沉淀 AIGC 创作交流圈，激发用户创作欲望的转化。

    多维度打造数据沉浸 / 多样性

    看入迷 → 想做 → 传播

    【内容多样性】

    从数据和视觉双维度打造沉浸感

    【短剧】从碎片化走向连续叙事，极大丰富内容品类，拉长用户停留时长及粘性

    【Featured】运营精选，强视觉冲击力，刺激用户产生创作的钩子
    【New】社区发的最新的趋势作品

    【浏览沉浸感】

    从数据和视觉双维度打造沉浸感

    【预加载】80% 预加载保证用户观看的流畅度，过滤已浏览，避免重复

    【TAB】去底色弱化，将视觉干扰降到最低
    【视频适配】内容不同比例适配规则，适配最佳观感

    【互动与创作转化】

    搭建评论和分享作为转化的阵地

    【评论】以评论为阵地，承载创作交流，将“围观灵感”直接转化为“二次创作”的裂变触发

    【分享】打破数据内循环，用一键分享在社媒构建“带链接的免费广告牌”，实现流量外循环

    资产的生命周期管理-创作内容的承接

    资产库不是存储功能，而是粘性引擎。用户生成和上传的资产越多，迁移成本越高、复用越频繁、社交价值越大、付费意愿越强，打造沉浸式观感、从底层撬动用户参与及创作、带动用户创作。从看见高质量作品到想做最后再做

    资产生命周期的循环

    将资产的整个生命周期管理利用起来，二次创作、裂变传播、互动回流

    商业化如何嵌入创作循环

    商业化不作为独立入口打断创作，而是随着用户从观看、尝试、持续创作到内容传播的不同阶段，在额度、能力和效率需求出现时提供对应的升级选择。

    流程
    用户行为 🙇
    商业嵌入 💰
    1内容触达
    浏览短剧 / 社区作品 → 获取灵感 → 产生创作意愿。
    观看转创作在 Drama、社区和活动内容强化 Create、挑战赛等创作入口，承接观后创作意愿。
    2首次创作
    注册获取免费体验次数 → Create / Agent → 完成一次创作
    免费额度促成首创新人赠送 Lumens、活动免费次数、Agent 自然语言入口和 Start Creating 跳转，降低首次创作门槛。
    3创作深化
    多轮生成 → 尝试高级模型 / Agent → 权益不足 → 订阅 / 购买 Lumens → 继续生成
    权益驱动持续创作建立会员等级、模型、Agent 会话等限制，明确不同方案可使用的更高创作能力。支付后直接继续生成。
    4资产沉淀与传播
    生成 → 保存 → Remix / Use Prompt → 发布 / 参与 / 分享
    复用与分享促增长对内置挑战赛的奖励机制鼓励用户多参与创作消耗，对外支持跳转分享至外部平台的传播。
    5触达回流
    获得点赞 → 推送互动消息 → 作品详情 查看反馈 → 继续创作
    消息触达带动回流通过本地推送、远程推送和互动消息，将用户带回创作、订阅、作品详情或首页。版本更新提示。
